## 一、背景与痛点

六年级男生每天要带的东西又多又杂：作业本、课本、铅笔盒、水杯、体育课跳绳、美术课水彩笔……经常早上出门前手忙脚乱，**不是忘带作业被老师批，就是忘带跳绳上不了体育课**。

痛点本质：**孩子不是不想带齐，而是缺少一个「按今天课表自动列出该带清单、逐项核对」的工具**。家长提醒一遍遍说，孩子还是记不住。

## 二、创意与解决方案

**小书包 = 孩子的「出门前智能检查官」。**

1. 孩子先在「课表」里把每天上什么课、对应要带什么录好（一次设置，长期用）。
2. 每天打开 App，自动根据**今天星期几**汇总出「今天该带清单」。
3. 出门前逐项勾选，进度条实时更新；**全勾 → 弹出「🎒 全部带齐，出发吧！」**。
4. 连续带齐天数变成「连击勋章」，用游戏化激励养成好习惯。

创意点：把「家长唠叨」变成「孩子自己玩着检查」，用**自动化 + 游戏化**解决真实生活麻烦，符合「小智能」让生活更便捷、更智能的主旨。

## 四、技术架构

- **形态**：纯静态网页（GitHub Pages 托管，评委手机点链接即用）
- **前端**：原生 HTML + CSS + JavaScript（零依赖、零构建，浏览器直接跑）
- **存储**：`localStorage`（课表、物品、记录存本地，无需服务器）
- **响应式**：手机优先，大按钮、大圆角、活泼配色（蓝/橙/绿）
- **为什么要网页不是 APK**：评委零安装、不挑机型、不怕安全拦截；提交只需发一个链接 + 录屏 + 文档

## 五、界面设计

- **受众**：六年级男生 → 活泼、卡通、不幼稚；大图标 + emoji；蓝(#2D7FF9)/橙(#FF9F43)/绿(#22C55E) 三色体系
- **五个视图**：今日 / 课表 / 物品库 / 成就 / 设置（底部 Tab 切换）
- **今日页**：顶部星期大字 → 中部物品勾选卡 → 底部进度条 + 「完成检查」按钮
- **成就页**：大数字「连续 N 天」+ 勋章墙
