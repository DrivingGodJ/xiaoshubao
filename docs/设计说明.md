## 一、作品概述

**一句话创意**  
「根据今天课表，自动生成出门前该带的东西清单，孩子自己逐项核对，全勾齐了就能出门。连击带齐天数解锁勋章，让好习惯越用越爽。」

**核心定位**  
「出门前的智能检查官」——一个家长省心、孩子主动的小工具。

## 二、痛点与目标

### 真实痛点（身边观察）

六年级孩子的书包既多又杂：作业本、课本、铅笔盒、水杯、跳绳、水彩笔、画纸……上课科目每天变、需要带的东西也每天变。常见三类麻烦：

| 类型 | 典型场景 | 结果 |
|---|---|---|
| 🔴 忘带作业 | 早上匆匆忙忙忘检查 | 被老师批评、扣分 |
| 🔴 忘带跳绳 | 体育课临时打电话求救 | 影响体育课参与 |
| 🔴 忘带美术工具 | 上课画画才发现没带 | 只能看别人画 |

孩子的痛点**不是不想带齐，而是没有结构化的清单 + 即时反馈的工具**，家长一天叮嘱三遍还是忘。

### 设计目标

1. **自动化** —— 不让孩子每次从头想，根据今天课表自动生成清单。
2. **游戏化** —— 用连击、勋章、视觉反馈把"检查"变成"想玩的游戏"。
3. **零门槛** —— 不用注册、不用安装、点链接就开用，评委手机扫一下也能互动。
4. **可定制** —— 课表、物品库都能改，适配每个孩子的真实情况。

## 三、核心功能

### 1️⃣ 今日智能清单

根据今天星期几，**自动汇总**所有课程关联的物品。当不同学科有相同物品时（比如语文和数学都有「作业本」），会**按学科分别列出并标注来源**，避免搞混：

> 📒 作业本 · 语文 | 📒 作业本 · 数学 | 📚 课本 · 语文 | 📚 课本 · 数学 | ✏️ 铅笔盒 · 语文 | ✏️ 铅笔盒 · 数学 | 🧣 红领巾 · 语文 | 🪢 跳绳 · 体育 | 👟 运动鞋 · 体育 | 🥤 水杯 · 体育

每项点击切换勾选，进度条实时更新到 **10 / 10 · 全部带齐🎉**。

### 2️⃣ 课表自定义

周一到周日每天一个卡片：
- 添加课程（如「英语」「信息课」「围棋班」）
- 每个课程多选关联要带物品
- 一键删除课程

### 3️⃣ 物品库管理

12 种六年级学生最常见的预设物品（作业本、课本、铅笔盒、水杯、跳绳、运动鞋、水彩笔、画纸、红领巾、雨伞、游泳镜、加餐），可直接添加自定义物品（如「科学书」「游泳裤」），自动从课表关联中移除已删除物品。

### 4️⃣ 成就与连击

- 🔥 **连续带齐天数**：连击数字 1 → 3 → 7 → 30，激励孩子坚持。
- 🥉 **坚持 3 天**（streak ≥ 3）
- 🥈 **一周全勤**（streak ≥ 7）
- 🥇 **月度达人**（streak ≥ 30）

未达成时勋章呈灰色，已达成变金色高亮，让孩子有明确的"下一个目标"。

### 5️⃣ 演示模式（作品展示用）

URL 加 `?demo=mon|tue|wed|thu|fri|sat|sun` 强制把「今天」设为对应星期，方便评委/演示者查看任意一天的清单，不受真实日期限制。

## 四、技术实现

| 项目 | 方案 | 说明 |
|---|---|---|
| 形态 | 纯静态网页 | 评委手机/电脑点链接即用，免安装、跨平台 |
| 前端 | 原生 HTML + CSS + JS | 零依赖、零构建，浏览器直接跑 |
| 数据 | `localStorage` | 课表、物品、记录存在本地，无需服务器、无隐私风险 |
| 响应式 | CSS Media + `max-width:480` | 手机优先，桌面访问时居中显示 |
| 部署 | GitHub Pages | 免费、稳定、HTTPS、可点即用 |
| 备份 | 源码随邮件附件 | 评委也能离线打开所有源码 |

**为什么选网页而不是安卓 APP？**
- 评委**零安装、不挑机型、不怕安全拦截**
- 作品只需发一个链接 + 录屏 + 文档，简洁
- 跨平台：Android、iPad、Windows、Mac 任意设备都能跑

## 六、使用流程

1. **第一次**：家长帮孩子在「课表」页录入一周的课表和对应物品；在「物品」页补齐孩子专属物品。
2. **每天早上**：孩子打开链接 → 「今日」自动列出今天该带的 → 逐项勾选 → 「完成今日检查」赢连击。
3. **一周回顾**：周末在「成就」页看本周带齐记录，养成习惯。
