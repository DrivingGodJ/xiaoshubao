# 小书包 · 出门前智能检查官

> 🎒 **小智能 · 创新行动参赛作品** —— 把「家长每天唠叨带什么」变成孩子主动完成的出门仪式。

## 一句话创意

根据今天的课表，自动列出今天该带的每一样东西，逐项勾选核对，全勾齐了 → 出发！连击带齐天数，解锁勋章。

## 演示链接

👉 直接用手机或电脑浏览器打开：

```
https://drivinggodj.github.io/xiaoshubao/?demo=mon
```

（`?demo=mon` 把「今天」强制设为周一，方便评委看演示效果。去掉参数则按真实系统日期。）

## 关于部署

本作品是一个**纯网页应用**（HTML + CSS + JavaScript），评委 / 老师用手机或电脑浏览器打开下方「演示链接」即可体验，无需安装任何 App。完整源码见 `index.html` / `app.js` / `styles.css`，用任意浏览器打开 `index.html` 即可在本地运行。

## 核心功能

| 页面 | 功能 |
|---|---|
| 📅 **今日** | 根据星期几自动汇总今天该带的东西，逐项勾选，进度条 0/7 → 7/7「全部带齐🎉」 |
| 🗓️ **课表** | 周一~周日每天可添加「课程/活动」并关联要带物品，预设常见课表可改 |
| 📦 **物品库** | 12 种预设常见物品 + 自定义添加（如「科学书」「游泳裤」） |
| 🏆 **成就** | 连续带齐天数 🔥、总检查次数、🥉坚持3天 / 🥈一周全勤 / 🥇月度达人 勋章 |
| ⚙️ **设置** | 演示模式切换「今天」、清空数据 |

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 技术栈

- 纯前端：HTML + CSS + 原生 JavaScript（零依赖、零构建）
- 数据：浏览器 `localStorage`（无服务器、无外网依赖）
- 部署：GitHub Pages（静态托管，评委零安装点开即用）
