# 小书包 · 出门前智能检查官

今天有体育课，运动鞋带了吗？小书包根据课表列好当天要带的东西，让孩子自己检查、自己勾选，再带着装好的书包出门。

[打开演示](https://drivinggodj.github.io/xiaoshubao/?demo=mon)

## 让课表变成出门清单

在周一到周日的课表中添加课程和活动，关联需要的物品。“今日”会把它们汇总起来，不必每天重新想一遍该带什么。

## 每勾一项，都离出发近一点

逐项检查书本、文具和活动用品，看进度从未完成走到全部带齐。物品库预置 12 种常见物品，也能添加科学书、游泳用品等自己的项目。

## 把坚持看得见

记录连续带齐天数和总检查次数，用坚持勋章鼓励孩子形成习惯。家长可以帮助调整课表，日常检查由孩子主动完成。

## 开始体验

手机和电脑浏览器都能打开，无需安装 App。演示链接固定展示周一，方便体验完整清单；去掉 `?demo=mon` 后跟随实际日期。
